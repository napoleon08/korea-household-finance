# 4차시 — 데이터 시각화 및 전처리

## 1. 데이터 개요

대한민국 17개 시도의 가구당 평균 부채와 가구당 평균 소득 데이터를 사용하였다. 데이터의 행과 열, 자료형, 결측치 현황을 확인하여 분석에 사용할 수 있는지 점검하였다.

## 2. 데이터 시각화

지역별 가구당 평균 부채를 비교하는 그래프와 가구당 평균 소득과 부채의 관계를 확인하는 산점도를 작성하였다.

그래프를 통해 지역마다 가구당 평균 부채와 소득 수준에 차이가 있음을 확인하고, 두 지표 사이의 관계를 탐색하였다.

## 3. 결측치 처리

분석에 필요한 주요 열의 결측치 여부를 확인하였다. 결측치가 있는 경우 해당 행을 분석 데이터에서 제외하도록 처리하였다. 실제 결측치 개수와 처리 전후의 행 수는 프로그램의 출력 결과를 기준으로 기록한다.

## 4. 이상치 처리

IQR 방법을 이용하여 이상치 후보를 탐색하였다. 그러나 지역별 데이터는 17개 시도만을 포함하므로, 값이 크거나 작다는 이유만으로 해당 지역을 삭제하지 않았다. 실제 지역 간 경제적 차이일 가능성을 고려하여 원본 값을 유지하였다.

## 5. 분석의 한계

분석 대상이 17개 시도로 제한되어 있어 표본 수가 적다는 한계가 있다. 또한 부채는 2024년 3월 기준이고 소득은 2023년 기준이므로 기준 시점이 완전히 일치하지 않는다. 계산한 DTI는 지역별 평균 부채와 평균 소득을 이용한 근사 지표이며, 개인별 DTI 또는 DSR과 동일하지 않다.

따라서 분석 결과를 모든 가구의 재정 상태로 일반화하는 데 주의해야 한다.
